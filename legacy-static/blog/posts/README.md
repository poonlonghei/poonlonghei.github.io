# Blog posts

Each HTML file in this directory is an individual article. Use `new-website.html` as the layout reference for the title, subtitle, publication date, reading time, article contents navigation, social sharing links, and return link.

For a new post, also add a dated post card to `../index.html`. Use `data-post-date="YYYY-MM-DD"` on the card so the blog’s Archive menu includes the article under the correct month. Link the card title to the post file.
