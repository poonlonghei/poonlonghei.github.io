# Stylesheets

Stylesheets are grouped here by the pages or components they support:

- `home.css` — homepage, including the About portrait’s floating glow, animated border, and reduced-motion styling
- `resume.css` — resume page
- `portfolio.css` — portfolio page
- `gallery.css` — photo gallery page and responsive photo grid
- `blog.css` — blog listing
- `blog-post.css` — individual blog posts
- `blog-archive.css` — shared archive dropdown on the blog and posts
- `desktop.css` — larger-screen layout refinements shared across all pages (applies at 1024px and wider)

The pages link to these files directly; there is no CSS build step.
