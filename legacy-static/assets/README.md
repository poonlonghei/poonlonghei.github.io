# Website assets

This directory contains the site’s stylesheets, browser scripts, and TypeScript source files.

- `css/` — page and component styles
- `favicon/` — website favicon files
- `js/` — scripts loaded by the website in browsers
- `photos/` — photography used on the site; `photos/gallery/` holds images for `gallery.html`
- `ts/` — TypeScript source for shared site behavior

When updating TypeScript, regenerate the matching JavaScript in `js/` before deploying. See the README files in each subfolder for details.
